# DMX USB Interface firmware

Free firmware releases of the **DMX Core USB Interface** for the [DMX Core Pico 2](https://dmxcore.com/pico).
With it the board is a two-port USB DMX interface with RDM, for lighting software on
Windows, macOS and Linux.

**Documentation: [docs.dmxcore.com/usb-interface](https://docs.dmxcore.com/usb-interface/)**:
installing the firmware, wiring, lighting software, the DMX Core USB Interface Utility, settings and
troubleshooting.

## Download

Get `dmxcore-pico2-usb-interface-<version>.uf2` from [Releases](../../releases). Each
release lists what is new.

To install it, follow [Installing the Firmware](https://docs.dmxcore.com/usb-interface/installing-firmware/),
or use the [USB Interface Utility](https://docs.dmxcore.com/usb-interface/config-utility/),
which finds and installs new releases for you.

## Issues

Report problems in [Issues](../../issues), with the firmware version (shown in the DMX Core USB
Interface Utility) and what you were doing.
